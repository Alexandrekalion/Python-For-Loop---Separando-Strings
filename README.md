# For Loop em Python: Separando Strings

Projeto educacional em Python criado para praticar o uso de `for` na iteracao de caracteres de uma string.

O exercicio recebe uma palavra digitada pelo usuario, converte o texto para letras maiusculas e imprime cada caractere com espaco, demonstrando como percorrer strings em Python.

## Objetivo do estudo

O objetivo e entender que strings podem ser percorridas caractere por caractere usando um laco `for`. O projeto tambem pratica transformacao de texto com `upper` e exibicao personalizada no terminal.

## Problema praticado

O exercicio resolve um desafio simples de formatacao: receber uma palavra e apresentar seus caracteres de forma separada, reforcando o conceito de iteracao.

## Como funciona

O programa solicita uma palavra pelo terminal. Em seguida, converte o texto para letras maiusculas e percorre cada caractere com `for`, exibindo o resultado na mesma linha.

## Conceitos utilizados

- Entrada de dados com `input`.
- Iteracao com `for`.
- Manipulacao de strings.
- Metodo `upper`.
- Impressao com controle de final de linha usando `end`.
